# Orbit 第二轮：先判断黑白轮廓

沿用已核对的 Sagi Haviv、Logo Design Love 与 Adobe 方法。本轮不依靠陶土色或展示背景，比较四种图形结构；内置 imagegen 生成概念图，修正首张异常暗底后保存 directions-efgh.png。

| 方向 | 想法 | 当前判断 |
| --- | --- | --- |
| E 偏心视窗 | 偏心留白的 O，外缘浅切口 | 既能读为 O，又有独立剪影。切口在小尺寸下需要实测；优先保留。 |
| F 双弧交会 | 两段厚弧与水平负空间 | 简单稳定，但过于通用，易被理解成交通/设备符号；图中字标意外采用小写 orbit，未定稿。 |
| G 定位切口 | 方形外框、圆形留白、向内定位点 | 与观测工具关联更强，但也可能联想到相机或雷达，需要相似性评估。 |
| H 字母连写 | 方圆 O 和定制 rb 字距衔接 | Header 紧凑，适合字标路线；单独 O 的识别性弱，连字仍需矢量重画。 |

建议优先 E，其次 G。若倾向只保留字标，则比较上一轮 D 与本轮 H。当前为位图方向图，不是已通过16px或商标相似性检查的最终资产，未替换网站 Logo。
