# ORBIT 查询与观测界面

状态：v0.5 动态地球交互契约已确定，实现已完成，浏览器验收见 docs/design/orbit-motion-review.md；既有页面结论以 [ORBIT 评审](orbit-review.md) 为准。用户批准的视觉基线为 [ORBIT direction comp](../../.impeccable/mocks/decision/orbit.png)；它约束构图与气质，不证明页面运行、动效或上游数据可用。

## 模式与成功标准

`/` 与 `/myip` 都是 Operate 型界面。用户应能直接查询、比较来源、辨认观测范围，并在部分成功或失败后继续操作。产品显示名是 **ORBIT / 地址观测**；仓库、GitHub 地址和部署域名继续使用 `leveling.zone`。

## 查询页

- 初始态使用深色连续画布和大幅 hero：左侧为“看见地址，读懂网络。”、真实查询表单与模式说明，右侧为完整轮廓的动态 ASCII 地球。[WebP v2](../../public/images/ascii-orbit-hero-v2.webp) 与 [PNG v2 原稿](../../public/images/ascii-orbit-hero-v2.png)继续保留为历史视觉基线素材。
- 无查询目标时地球低速自转。当前 `QueryResult` 中被选择的来源同时提供有限、合法经纬度后，地球沿最短旋转路径平滑转向该位置，跨越 ±180° 经线时不绕远；抵达后显示目标标记。hero 从初始态收紧时延续朝向和标记。
- 用户可暂停或继续空闲自转；暂停状态下，新查询仍可执行一次目标定位，抵达后保持静止。控制必须可键盘操作并有明确的“暂停地球转动”或“继续地球转动”名称。
- 当前查询没有有效坐标时保留上一视角、移除本次目标标记，并显示“本次查询未提供可定位坐标，保留上一视角”一类说明；首次即缺少坐标时保留默认视角且不显示标记。不得用 IP、ASN、组织名推断坐标，也不得将空值映射为 `0,0`。
初始查询页不展示任何样本结果或示例 IP 按钮，仅显示输入提示。只有实际查询返回的结果可以进入来源表。
- 获得有效 `QueryResult` 后，hero 切换为紧凑变体，标题、输入、模式与按钮保留在同一 DOM；结果概览和全宽来源表成为主要阅读内容。
- 表格保留来源、ASN/组织、地理位置和详情四列；桌面使用全宽稳定列，移动端转换为带字段 label 的纵向条目。原始 JSON、完整 IPv6、缺失值与来源错误都可检查。
- 新查询失败时保留旧结果并标成“上次查询结果”；503 的完整响应继续显示可用来源与错误。非 JSON 响应使用专门的“收到无法识别的响应”格式异常提示，不与连接失败混写。图像只作装饰，真实坐标只来自当前选中的有效 source。

## `/myip`

`/myip` 从进入页面起使用同一 hero 的紧凑观测变体，标题为“看见此刻的连接。”。成功项按 `observation.scope` 分为“请求地址观测”和“服务器出口观测”，每行展示自身返回的 IP；失败项进入全局数据源问题列表，不生成虚构的分组失败率或设备位置。由于页面可能同时包含请求地址和多个服务器出口，地球固定使用装饰性缓慢自转，可暂停，但不选择其中一个坐标自动跳转或显示位置标记。

## 响应与可访问性

桌面容器最大宽度 1600px，768px 以下导航换行、查询动作纵向排列、表格转换为移动条目。1200px 以上的观测视图始终展开，summary 移除 marker、Tab 停靠和点击折叠能力，作为不可操作的区块标题；更窄视口才提供真实 disclosure。动态地球的字符图形不进入可访问名称，旁边以文本说明自转、暂停、定位或坐标缺失状态。系统开启 `prefers-reduced-motion: reduce` 时停止连续自转和插值转场，有效目标直接切换视角并显示标记；查询、数据与状态反馈保持不变。焦点、错误、partial、loading 和复制反馈继续使用语义文字。动效验收至少覆盖桌面与移动端的自转、暂停、有效坐标定位、跨 ±180° 最短旋转、连续查询、坐标缺失保留、`/myip` 装饰模式和 reduced motion；通过前不得把本契约描述为已验证实现。


## 查询驱动的 Motion（当前规则）

地球在等待查询时保持静止，不提供暂停/继续按钮。查询返回有效坐标后自动转向当前来源位置，抵达后停住并显示标记；切换来源会再次定位。新查询没有有效坐标时保留视角并清除标记。系统减少动态效果时直接定位。此规则替代前文的空闲自转与手动暂停说明，`/myip` 无统一目标，因此仅显示静态地球。

## 我的 IP 范围更新

`/myip` 已从混合观测改为只查询访问者公网 IP；API 使用 Node.js 本地数据库查询，默认不联系第三方，返回 request-ip 语义。页面只展示访问者结果，拒绝旧 mixed/服务器出口响应及 IP 不一致条目。地球保持示意状态，样本数据与示例按钮均不提供。
